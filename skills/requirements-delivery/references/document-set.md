# 文档集

只创建能解决当前问题的文件。默认路径沿用项目已有约定；没有约定时使用 `doc/<工单号>/`。

| 文件 | 何时创建 | 只记录什么 |
|---|---|---|
| `系统分析.md` | 需求和真实现状有重要差异，或存在关键边界 | 目标、事实、差异、结论、风险、验收 |
| `详细设计.md` | 实现涉及跨模块契约、复杂数据流、权限、迁移、并发或回滚 | 入口、文件/方法、调用链、数据、步骤、伪代码、异常、验证 |
| `开发清单.md` | 多 Task、跨会话或需要状态追踪 | Task、依赖、当前状态、验收信号、证据、下一步 |
| `当前上下文.md` | 清单不足以支持长周期恢复 | 活跃 Task、有效结论、阻断、下一步 |
| `测试计划.md` | 多环境、多阶段或多类型验证需要矩阵 | 验证范围、状态和证据索引 |
| `过程记录.md` | 用户要求审计/复盘，或长篇历史仍有价值 | 历史过程，不写当前状态 |

## 单一来源

- 结论只维护在系统分析或详细设计的对应章节。
- Task 状态只维护在开发清单的 Task 明细；总览只显示摘要。
- 验证证据只维护在当前 Task，测试计划只做矩阵索引。
- 不为模板章节填充无关内容，不复制长篇背景和终端流水。
